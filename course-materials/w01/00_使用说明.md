# W1 材料包使用说明

> 材料版本：`w01-materials-0.2.4`。访谈入口、截止时间由班期配置。本包中的青禾优选、人物、邮件和样例数据均为虚构教学材料。

本周从接手标准产品开始，为青禾优选形成进场判断。本页说明材料在哪里、先读什么；具体任务、操作、自检和提交要求见[作业任务书](05_作业任务书.md)。

## 文件与阅读顺序

1. [沈总立项邮件](01_沈总立项邮件.md)：了解客户的初始诉求。
2. [公司与项目协作关系](02_公司与项目协作关系.md)：了解参与角色及分工。
3. [产品核查指引](03_产品核查指引.md)：定位产品文档、能力矩阵与核查依据，配合[工程包](工程/fde-student-w01-0.2.0.zip)阅读。
4. [立项四问与访谈提纲](04_立项四问与访谈提纲.md)：准备首轮访谈问题。
5. [作业任务书](05_作业任务书.md)：按其中的要求执行、验证和提交。

填写 fit-gap 使用[初步版空白表](06_fit-gap空白表.xlsx)和[转换工具](07_fit_gap_to_json.py)，初步版要求、待判断、填写转换及后续修订规则统一见任务书。

[C01 Morgan Stanley 案例手册](案例手册/C01_Morgan_Stanley.md)可配合 V06 的 9 页案例课阅读，涵盖六格概览、应用流程、需求与交付责任、评估解读、立项四问模拟、小规模验证安排及青禾优选迁移问题。手册用于理解工作方法，不提供青禾优选的标准答案，也不增加独立提交文件。

## 版本与边界

本包对应产品 `0.2.0-w1`、能力矩阵 `w1-capabilities-0.2.0`；fit-gap 契约为 `w01-0.2.1`，其余三份 JSON 沿用 `w01-0.2.0`。本周使用上面链接的 `fde-student-w01-0.2.0.zip`；当前功能与使用边界见 ZIP 内的 `RELEASE.md`。

产品支持日期确认、拒绝草案后更换目标，并根据工具结果说明退款。模型请求默认使用 8192 token、90 秒；确认输出预算截断后，仅重试该次模型请求一次，临时使用 16384 token、180 秒，再次失败则报错。已完成的工具和动作不会随模型重试重复执行。推理参数按模型配置选择，详见工程 ZIP 内 `docs/model-configuration.md` 和 `RELEASE.md`。

使用其他模型时需按自己的接口适配；Windows、Linux 如遇问题，请反馈给课程方。

工程包提供标准产品源码、样例数据、接口文档和运行说明，包含 SQLite 导入材料、LangGraph Agent、标签 HTTP 参考连接器及有状态 Mock、Promptfoo 基础配置、OpenTelemetry 记录和 W1 契约。安装与配置细节以 ZIP 内的 README 为准；后续各周继续使用自己的客户交付工作目录。

产品里的松果生活是与青禾优选无关的独立样例。不要用它推算客户会员数或复购率，也不要把课堂故障注入当成客户系统的真实故障。

AI 客户由课程方提供，和你要运行、改造的标准 Agent 产品是两套系统。学员产品包不包含 AI 客户的隐藏设定，不要求学员部署教师系统。访谈入口按班期提供，访谈要求见任务书。


## 网关配置

课程已验证网关使用 `extra_body.thinking` 并显式绕过响应缓存；直连 DeepSeek 与通用接口分别使用各自配置，不将网关格式强加给其他模型。默认 8192 token／90 秒，以及确认输出预算耗尽后的一次 16384 token／180 秒重试保持不变。

W01 使用课程网关时选择 `FDE_MODEL_PROFILE=gateway-low`，业务判断与工具调用保留低推理。模型参数和其他模型的适配边界见工程内 `docs/model-configuration.md`。
