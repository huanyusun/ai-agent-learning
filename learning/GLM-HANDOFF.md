# GLM-5.3-Flash 执行入口

目标：将现有 AI 学习资料整合为课程中心，并增加每周来源刷新、每月候选发现和更新报告。实施计划已写好，本文件不表示功能已完成。

## 可直接复制的启动提示词

```text
请在当前仓库实施以下计划：
docs/superpowers/plans/2026-10-28-learning-hub.md

先完整读取计划和 learning/ 下现有资料，然后执行 T01–T08。
使用当前 GLM-5.3-Flash，不需要调用其他模型或启动子代理。

必须遵守：
1. 先检查 git status；保留用户已有未提交修改。
2. 课程与周计划统一存 JSON，生成 Markdown 和原生静态页面。
3. 自动观测、人工策划、个人学习进度分别保存。
4. 主线保留 C01–C20、8 个阶段、18 周，不丢章节、A/B 核查与费用说明。
5. 每周检查来源；每月发现已配置官方目录的新候选。候选不直接加入主修。
6. 403/超时不判下架；更新器不修改人工标题、费用和学习顺序。
7. 每项任务先写有意义的离线测试，再实现；页面行为实际检查。
8. 不改 FDE 产品、W1 契约与交付物，不部署网站，不自动合并更新 PR。
9. 逐项更新计划复选框；每个任务结束记录改动、验证和遗留问题。
10. 无远端或工作流权限时完成本地实现和报告，并明确在线调度未验证。

建议分三个里程碑执行：M1=T01–T03，M2=T04–T06，M3=T07–T08。
持续推进到完成，不把设计说明当作实现。确有外部阻塞时记录真实原因，
继续完成不依赖它的任务；不要编造检查通过或上线状态。

进度和验收记录写入 learning/IMPLEMENTATION-RESULTS.md。
最终报告入口、运行命令、测试结果、自动更新是否真正启用及已知限制。
```

## 最终应交付什么

- 统一页面：`learning/index.html`。
- 数据与可重建文档：`learning/data/` 和原有导航文件。
- 本地命令：validate、build、refresh、discover。
- 自动更新：Actions 配置、固定更新 PR、无权限时的报告回退。
- 维护手册、离线测试及真实验收记录。

计划内的文件路径是实施目标，当前可能尚不存在；以实施记录确认实际完成情况。
